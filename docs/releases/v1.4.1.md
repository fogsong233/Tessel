# Tessel v1.4.1

Tessel 1.4.1 turns handwriting into a first-class part of the PDF workspace
and adds a low-latency tablet companion that works over the local network.

## Handwritten notebooks

- Keep one fixed notebook beside each PDF page, opening on the left by default.
- Add any number of vertically scrollable sheets inside the notebook; existing
  left and right canvases are preserved as sheets in the new layout.
- Draw with pressure-sensitive strokes, choose color and size, or enable
  stylus-only mode so fingers remain available for navigation.
- Lasso strokes to move, resize, or delete them.
- Send a lasso selection to the current AI conversation as a PNG attachment.
  Tessel creates a page conversation and prepares the attachment when no chat
  is open, without sending a prompt automatically.

## Tablet companion

- Open the local handwriting page from the QR code in Settings while the
  tablet and computer share a network.
- Browse every notebook sheet, create and delete sheets, move the whole
  notebook between PDF sides, and use the canvas in fullscreen.
- Stream frame-batched stroke previews with persisted commits for low latency.
- Keep pen coordinates stable while the browser resizes or the sheet list is
  moving, and allow edge strokes to be selected reliably.

## Interface and reliability

- Restyle the tablet interface to match Tessel's restrained yellow, ink, and
  paper visual language across desktop, landscape tablet, and narrow screens.
- Use a compact notebook header and a narrow modern internal scrollbar.
- Keep handwritten notebooks aligned with their PDF page through zoom changes
  and clear of an open conversation dock.
- Expand the release regression suite to 30 passing scenarios, including the
  complete desktop and local-network handwriting flows.

The installer updates only the application bundle. Existing PDFs, reading
sessions, settings, credentials, conversations, and handwritten strokes remain
in Electron's user-data directory.
