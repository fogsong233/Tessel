# Tessel v1.5.1

## English

### What changed

- Added an **Automatic updates** preference in Settings. Background checks and downloads can be disabled while manual checks remain available.
- Restored circular controls for the Chat, Translation, Notes, create, and move buttons in the reading dock.
- Reworked selected states to use the surrounding surface and border system without the flat left-side stripe.
- Restored the left sidebar reveal and hide animation.
- Matched the outline scrollbar track to the sidebar background instead of using a white track.
- Improved Windows update installation and restart behavior for custom installation directories.

### Update notes

- Windows: use **Settings → Updates → Check for updates** or the automatic update flow.
- macOS: this unsigned build must be updated manually from the installer assets below.

## 中文

### 更新内容

- 在设置中加入“**自动更新**”开关。关闭后会停止后台检查和下载，但仍可手动检查更新。
- 恢复阅读侧栏中“对话、翻译、笔记、新建和移动”等按钮的圆形样式。
- 重做选中状态，改为使用当前界面的背景和边框体系，移除突兀的左侧平面色条。
- 恢复左侧栏呼出和隐藏时的动画。
- 将目录滚动条轨道改为侧栏底色，移除纯白背景。
- 改进自定义安装目录下 Windows 更新的安装和重启流程。

### 更新方式

- Windows：前往“设置 → 更新”，点击“检查更新”，或使用自动更新流程。
- macOS：当前为未签名版本，需要使用下方安装包手动更新。
