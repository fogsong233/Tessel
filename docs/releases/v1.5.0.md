# Tessel 1.5.0

这次更新集中打磨阅读、对话与手写工作台：更清晰的文字、更克制的界面，以及从窄侧栏到宽屏都稳定的布局。

## 统一界面与阅读体验

- 统一设置、目录、聊天面板的圆角、间距、边框和文字层级，减少厚重阴影、渐变与胶囊式控件。
- 改进 Windows 中文字体回退，放大局域网连接区的地址与说明文字；连接地址突出 IP 和端口，复制按钮与二维码仍包含完整连接密钥。
- 宽屏聊天输入区、附件与配置区居中，最大宽度为 **720px**；模型菜单不再随侧栏无限拉伸。
- 支持分别调节界面、目录、回复、输入和代码字号，修复外观设置与大字号下的布局溢出。
- 调整搜索导航、附件、圈选与权限等图标，让外观与实际操作对应。

## 对话与手写

- 可通过当前对话的模型菜单或 `/model` 调整 Codex 模型与推理强度，权限设置独立保留。
- 优化 PDF 上下文准备和连续对话路径，减少重复准备工作。
- 手写笔刷支持收藏、更易调节的宽度，以及平滑与跟手程度设置。
- 完善桌面与平板工具栏、撤销/重做、触控禁写与触控笔交互；纸张列表可以收窄或隐藏。
- 平板设备可选择信任，后续连接无需反复输入会话密钥。

## 稳定性与更新

- 修复窗口调整、PDF 缩放、短聊天面板和笔记编辑器布局的稳定性问题。
- 手写输入会取消尚未完成的缩放定位，避免落笔时纸张突然移动。
- 清空 PDF 搜索时同步移除搜索高亮，不影响原有标注与文字选中效果。
- 改进 Windows 下载后重启安装流程；更新说明以 Markdown 显示。
- 增加逐界面截图与宽窄窗口回归检查，覆盖全部设置分区、聊天、笔记和局域网手写板。

## 安装说明

Windows 可下载 `.exe` 安装包，macOS 可下载 `.dmg`。安装器替换应用程序，不会迁移或清空原有 PDF、书库、对话、笔记和手写数据。macOS 构建暂未签名，系统可能需要手动允许打开。
