# Tessel v1.5.2

## English

### Faster Codex and reliable message rendering

- Reuse the background Codex process for chat and translation. Changing unrelated settings no longer restarts Codex, and saved conversations resume their existing threads.
- Reduce translation setup with a compact text context, no web search, and a fast available model when no translation model is selected.
- Cache parsed PDFs and extracted page text. CLI compatibility mode now receives the same built-in PDF tools through a temporary local MCP connection, so reading text no longer requires a separate `pdftotext` process.
- Render Codex file citation markers as clickable links instead of raw trailing characters. Preserve fenced and inline code during Markdown and math conversion.
- Keep images mounted during streaming, load local images reliably, and show a source link when an image cannot be loaded.
- Handle final stream corrections and incomplete last JSON lines without duplicating or losing response text, including conversations with mid-turn guidance.
- Preserve deliberate PDF panning after dock menus close or message height changes.

### Rebuilt browser whiteboard

- Browse adjacent sheets in one continuous scroll surface, with stylus writing, one-finger scrolling, and two-finger zoom.
- Use a shared toolbar and redesigned brush controls. Pen, color, and finger-writing preferences persist across sheets.
- Improve ink responsiveness and keep live and saved strokes visually consistent.
- Preserve new strokes and undo operations when delayed acknowledgements arrive; serialize saves and deduplicate repeated commits to prevent disappearing handwriting.

### Update notes

- Windows: use **Settings → Updates → Check for updates**, or download the EXE installer below. A ZIP package is also available.
- macOS: this unsigned build requires a manual update using the DMG or ZIP below.
- The English and Chinese README files have been updated separately.

## 中文

### Codex 提速与消息显示修复

- 对话和翻译复用 Codex 后台进程；修改无关设置不再重启 Codex，已有对话恢复原来的线程。
- 翻译使用精简文本上下文，关闭网页搜索；未指定翻译模型时优先选择可用的快速模型，减少准备耗时。
- 缓存已解析的 PDF 和页文本。CLI 兼容模式通过临时本地 MCP 连接使用相同的内置 PDF 工具，读取文本无需另行启动 `pdftotext`。
- 将 Codex 文件引用标记显示为可点击链接，修复回答尾部出现原始标记的问题；Markdown 与公式转换不再误改代码块和行内代码。
- 流式输出时保持图片组件稳定，修复本地图片加载，并在图片无法加载时显示来源链接。
- 正确处理最终文本纠正及末尾没有换行的 JSON 事件，避免回答丢失或重复，同时兼容中途追加指令的对话。
- 关闭侧栏菜单或消息高度变化后，不再意外拉回用户主动平移的 PDF 视图。

### 网页手写板重构

- 多张纸在同一连续滚动区域中浏览，支持手写笔书写、单指滚动和双指缩放。
- 统一工具栏并重做画笔设置；画笔、颜色和手指书写开关跨页保留。
- 改善跟笔响应，保持书写过程中与保存后的笔迹外观一致。
- 延迟回执到达时保留新笔迹和撤销操作；串行保存并去除重复提交，修复写下的字随后消失的问题。
