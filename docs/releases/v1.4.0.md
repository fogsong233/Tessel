# Tessel v1.4.0

Tessel 1.4 focuses on a faster, cleaner Windows reading experience and makes
local reading data easier to revisit and understand.

## Highlights

- Reopen recently viewed PDFs directly from the focused start page.
- Inspect local books and their stored reading state, conversations, messages,
  translations, notes, annotations, bookmarks, generated outlines, and canvas
  items from the new Storage settings page. Secrets and Base64 attachments are
  excluded from this view.
- Render vector PDF content at the active zoom and device pixel ratio while
  preserving the PDF.js text and annotation layers for selection and marks.
- Enable Electron's GPU-accelerated compositor on Windows, with
  `TESSEL_DISABLE_HARDWARE_ACCELERATION=1` as a driver-compatibility fallback.
- Replace the Windows menu bar with compact maximize/restore and close controls;
  Settings now opens in a dedicated window.
- Hold Space and drag to pan the PDF canvas horizontally or vertically.
- Show concrete progress while AI generates a missing PDF outline.
- Improve Codex startup, model caching, native Windows executable discovery,
  active-turn guidance, and local path handling.

## Reliability and polish

- Restore start-page centering and keep chat composer controls on one row.
- Coalesce WebDAV metadata synchronization through the serialized workspace
  mutation queue.
- Use full-file SHA-256 identities consistently and keep recent translation
  metadata in WebDAV snapshots.
- Improve local and remote image handling without routing local paths through a
  localhost server.
- Add an installed-build preview script for rapid Windows validation with an
  automatic `app.asar` backup.
- Standardize release asset names so Windows update metadata resolves the exact
  installer uploaded to GitHub Releases.
- Expand the Electron end-to-end suite to 24 passing release scenarios.

The installer replaces only the application bundle. Existing PDFs, reading
sessions, preferences, credentials, and Codex workspaces remain in Electron's
user-data directory.
